# datetime 객체 
- `strptime()`: string parse time / 스트립 타임 
    - 문자열을 datetime 객체로 변환(파싱)해줌.
- `strftime()`: string format time / 스트프 타임 
    - datetime 객체를 내가 원하는 문자열로 포매팅 해줌 


### 함수 인자 
- `datetime.strptime(date_str, 현재 포맷)` -> datetime 객체
- `datetime_obj.strftime(바꾸고자 하는 형태의 포맷)` -> str

### 단계
> str -> strptime() 객체 파싱 -> strftime() 원하는 포맷으로 변환

1. 입력: "2026-07-01T10:15:30Z" (순수한 문자열)

2. strptime 단계: 이 문자열을 분석해서 datetime 객체로 변환함.

3. strftime 단계: 그 datetime 객체를 다시 "2026-07-01 10:15:30"이라는 정형화된 문자열로 변환함.

### 예외 처리 
- datetime은 파싱을 시도해보고 실패하면 예외처리 구조 EAFP 스타일을 장려함
- try - except 구문과 함께 쓰임 
- EAFP(Easier to ask for forgiveness than permission) - 아님말고, 사후처리형
- LBYL(Look Before You Leap) - if 문으로 미리 문제 없는지 실행, 사전 예방형 

### 자주 쓰는 날짜 포맷
%Y: 2025 
%m: 01 (zero-padded month)
%B: January 
%d: 03 (zero-padded day)
%A: weekday, Sunday

%p: PM, AM 
%H: Hour, 24-hour clock
%M: Minute, 24-hour clock
%S: Second

- 끝에 Z는 표준시(UTC) 기준 -> timezone 정보
