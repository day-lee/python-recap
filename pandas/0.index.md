# Index

- 대괄호 []: 데이터 차원(dimension) 결정하고, 내부 엔진에 접근 방식을 지시 
- SQL에서는 SELECT로 컬럼을 고르고, WHERE에서 행을 고름 
- 데이터프레임 바로 뒤 df[...] ➔ "기본적으로 열(Column) 중심"
- .loc 뒤 df.loc[...] ➔ "행과 열을 동시에 제어"
- 판다스 내부 엔진에게 좌표(Row, Column)를 한 번에 딱 찍어주는 것


### 판다스에서 인덱싱은 데이터 선택해서 다루는 도구 
- 행 이름 Index
- 열 이름 Column

- 시리즈: 1차원 데이터 Series
- 데이터프레임: 2차원 데이터 DataFrame 

- 대괄호 안에 조건식이나 슬라이싱이 들어오면 행row를 고른다. 

- df['컬럼명']: 브라켓 안에 `문자열` 전달, 해당 열 한개만 시리즈로 반환 
- df[['컬럼명']]: `리스트`를 전달, df로 반환. 
                리스트 아이템이 한개라도 한개 열을 가진 df로 나온다.  
                `df[['name', 'age', 'height']]`
- df[(조건식)]: `(조건식)`을 전달. 행을 필터링해서 df로 반환. 
              조건식은 ()괄호로 묶는다. 
              AND: () & () 
              OR: () | ()
              가독성을 위해 분리함. 
              kid_condition = (df['age'] < 12) | (df['height'] <= 150)
              kid_df = df[kid_condition]


### df.loc[]: label based location
- df.loc[행, 열] 
- df.loc[:, 열] -> 특정 열만 가져오기 
- df.loc[행, :] -> 특정 행만 가져오기 
- 조건문 필터링 
    df.loc[df['continent'] == 'Asia', 'Europe']
- 조건으로 필터링하면서 바로  df.loc[행_조건, [열 리스트 선택]] -> df 리턴 

- chained indexing으로 대괄호가 연속으로 두 번 쓰이면서 중간에 원본과의 연결고리가 모호해짐. 판다스 내부에서 이 변수에 담긴 객체를 새로운 메모리에 복사해서 줘야할지, 주소를 포인팅하는 뷰로 줘야할지 헷갈림. 메모리를 아끼고자 하는 판다스 내부 고민에서 기인함. 

- df.loc[조건, 열] (단일 인덱싱): 행과 열을 동시에 지정하므로 모호함 없이 원본에 정확히 접근함 → 안전함!

```
# 1단계: 조건에 맞는 행들만 임시로 골라낸다.
temp = df[조건식]  -> 이 temp 변수가 원본을 가리키는건지, 새로운 객체로 메모리에 복사해야할지 헷갈림 
-> temp = df[조건식].copy() 를 해주면 새로운 객체가 되어 이후 수정해도 경고 발생하지 않음.

# 2단계: 그 임시 결과에서 'name' 컬럼만 추출한다.
result = temp['name'] 

--
# 대괄호 한번으로 임시 객체에 바로 접근하여 모호함이 사라짐. 에러나지 않음.  
df.loc[조건식, ['name']]

```

## 🗺️ Pandas Indexing 전체 토픽 로드맵

### 1. 기본 인덱싱 (기반 다지기)
- **열(Column) 선택**: `df['A']` (시리즈) vs `df[['A']]` (데이터프레임)
- **행(Row) 슬라이싱**: `df[0:3]`처럼 숫자로 범위를 지정해 행 가져오기

### 2. 명시적 인덱서 (가장 중요한 핵심)
- **`df.loc[]` (Label-based)**: 컬럼명이나 인덱스 '이름'으로 행/열 선택하기
- **`df.iloc[]` (Integer-based)**: 0부터 시작하는 '정수 위치 번호'로 행/열 선택하기
- **`loc` vs `iloc` 차이점**: 슬라이싱할 때 끝값(상한선)이 포함되는지 여부 이해하기

### 3. 조건부 인덱싱 (실무 데이터 필터링)
- **불리언 인덱싱 (Boolean Indexing)**: `df[조건식]`을 활용해 원하는 행만 필터링하기
- **다중 조건 연결**: `&` (AND), `|` (OR), `~` (NOT) 연산자와 괄호`()` 활용법
- **`.isin()` 필터링**: 특정 리스트에 포함된 값들만 한 번에 쏙 골라내기 (예: `df['도시'].isin(['서울', '부산'])`)

### 4. 인덱스 제어 및 조작 (표의 축 바꾸기)
- **`.set_index()`**: 특정 컬럼을 표의 '행 인덱스(이름)'로 지정하기
- **`.reset_index()`**: 기존 인덱스를 일반 컬럼으로 되돌리고 0, 1, 2... 순정 인덱스로 초기화하기
- **인덱스 이름 변경**: `.rename(index=...)` 또는 `.rename(columns=...)` 활용법

### 5. 고급 인덱싱 (이후에 배우게 될 심화 과정)
- **멀티 인덱스 (MultiIndex / Hierarchical Indexing)**: 행이나 열에 계층(여러 층)을 만들어 복잡한 데이터 다루기
- **`.loc`을 이용한 데이터 수정**: 특정 조건의 데이터만 안전하게 값을 덮어쓰기 (SettingWithCopyWarning 방지)
